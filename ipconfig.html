Rede (ipconfig)

O ipconfig mostra os endereços de rede desta máquina. Nesta aula a coleta usou só a forma simples, sem a chave /all: não entram MAC, DNS completo nem o nome do host. Mesmo assim a saída trouxe sete adaptadores. A maioria apareceu com mídia desconectada. O que interessa para o dia a dia é o Wi-Fi, que nesta coleta (já anonimizada) mostrou o IPv4 192.168.0.10 e o gateway 192.168.0.1.

Você vai aprender
  • O ipconfig simples, sem /all, e a ler a lista de adaptadores.
  • Que um endereço 169.254.x é link-local: aparece quando não há DHCP.
  • Que 192.168.56.1, nesta coleta, é o endereço padrão do adaptador host-only do VirtualBox.
  • Que ipconfig /opcao-invalida devolveu Erro: linha de comando não reconhecida ou incompleta, seguido da ajuda.

Todas as saídas desta aula foram colhidas no Prompt de Comando de um Windows em português, na pasta de teste C:\Users\ana\guia-cmd-teste, e os endereços já vieram anonimizados. No seu computador, o comando mostra os endereços da sua máquina, que podem ser outros. Não inventamos nem traduzimos mensagem de erro.

A ideia: olhar o número da casa, sem pedir o documento

O ipconfig simples é o número na fachada: os endereços da máquina. O /all seria o documento completo (MAC, DNS, nome do host), e por isso ficou de fora desta aula.

No Adaptador de Rede sem Fio Wi-Fi, o IPv4 foi 192.168.0.10, a máscara 255.255.255.0 e o gateway padrão 192.168.0.1. Também apareceu o sufixo DNS lan. É neste adaptador que a máquina desta coleta fala com a rede da casa.

O Adaptador Ethernet Ethernet 2 mostrou 192.168.56.1, sem gateway. Esse é o endereço padrão do adaptador host-only do VirtualBox: uma rede só entre o Windows e as máquinas virtuais, não a rota da internet.

O Adaptador desconhecido Conexão Local mostrou 169.254.10.20, também sem gateway. Endereços 169.254.x são link-local: o Windows escolhe um sozinho quando não há DHCP nessa placa. Não é o endereço “de verdade” da rede da casa.

Quando dá errado

Uma chave que não existe

O ipconfig /opcao-invalida devolveu o erro abaixo e, em seguida, a ajuda completa do comando:

C:\Users\ana\guia-cmd-teste>ipconfig /opcao-invalida

Erro: linha de comando não reconhecida ou incompleta.

USO:
    ipconfig [/allcompartments] [/? | /all |
                                 /renew [adapter] | /release [adapter] |
                                 /renew6 [adapter] | /release6 [adapter] |
                                 /flushdns | /displaydns | /registerdns |
                                 /showclassid adapter |
                                 /setclassid adapter [classid] |
                                 /showclassid6 adapter |
                                 /setclassid6 adapter [classid] ]

onde
    adapter           Nome da conexão
                     (caracteres curinga * e ? permitidos; consulte exemplos)

    Opções:
       /?               Exibir esta mensagem de ajuda
       /all             Exibir informações completas sobre configuração.
       /release         Liberar o endereço IPv4 para o adaptador especificado.
       /release6        Liberar o endereço IPv6 para o adaptador especificado.
       /renew           Renovar o endereço IPv4 para o adaptador especificado.
       /renew6          Renovar o endereço IPv6 para o adaptador especificado.
       /flushdns        Limpa o cache do DNS Resolver.
       /registerdns     Atualiza todas as concessões de DHCP e registra
                        novamente nomes DNS
       /displaydns      Exibir o conteúdo do Cache do DNS Resolver.
       /showclassid     Exibe todas as IDs de classe dhcp permitidas para o
                        adaptador.
       /setclassid      Modifica a ID de classe dhcp.
       /showclassid6    Exibe todas as IDs de classe DHCP IPv6 permitidas para
                        o adaptador.
       /setclassid6     Modifica a ID de classe DHCP IPv6.


O padrão é exibir apenas o endereço IP, a máscara de sub-rede e
o gateway padrão para cada adaptador limitado ao TCP/IP.

Para Release e Renew, se nenhum nome de adaptador for especificado,
as concessões de endereços IP para todos os adaptadores limitados 
ao TCP/IP serão liberadas ou renovadas.

Para Setclassid e Setclassid6, se nenhuma ClassId for especificada, ClassId 
será removida.

Exemplos:
    > ipconfig                       ... Mostrar informações
    > ipconfig /all                  ... Mostrar informações detalhadas
    > ipconfig /renew                ... renovar todos os adaptadores
    > ipconfig /renew EL*            ... renovar qualquer conexão cujo nome
                                         seja iniciado por EL
    > ipconfig /release *Con*        ... liberar todas as conexões 
                                         correspondentes, por exemplo,
                                          "Conexão Ethernet com Fio 1" ou
                                         "Conexão Ethernet com Fio 2"
    > ipconfig /allcompartments      ... Mostra informações sobre todos os
                                         compartimentos
    > ipconfig /allcompartments /all ... Mostra informações detalhadas sobre
                                         todos os compartimentos
C:\Users\ana\guia-cmd-teste>

O que esta aula não pede para rodar

A chave /all mostra MAC, DNS e o nome do host. Ela aparece aqui só para você reconhecer o que fica de fora, sem caixa de execução:

FormaPor que não entra na prática desta aula
ipconfig /allMostra MAC, DNS e o nome do host. Esta coleta usou só a forma simples.

Formas diferentes

FormaQuando usar
ipconfigPara ver os endereços da máquina, sem MAC, DNS completo ou nome do host. Nesta coleta, o Wi-Fi veio como 192.168.0.10, com gateway.
ipconfig /opcao-invalidaNão use: a coleta devolveu Erro: linha de comando não reconhecida ou incompleta, mais a ajuda.

Referência rápida

Você digitaO que faz
ipconfigMostra os endereços de rede da máquina, na forma simples.
ipconfig /allMostra o relatório completo (MAC, DNS, nome do host). Sem caixa nesta aula.
