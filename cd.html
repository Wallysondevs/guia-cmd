Mudando de Pasta (cd)

Você já sabe olhar o que há na gaveta. Agora vai andar: entrar numa subpasta, subir um nível e perguntar de novo onde está. O cd (de change directory, “mudar de diretório”) faz esse caminho. Sem argumento, ele só mostra a pasta atual — não muda nada.

Você vai aprender
  • O cd sem argumento, que mostra a pasta atual.
  • O cd fotos, que entra numa subpasta, e o cd .., que sobe um nível.
  • O cd /d, que também pode trocar de disco (nesta aula, só apontando para a própria pasta de teste).
  • O sinônimo chdir.
  • Os erros reais de uma pasta que não existe e de tentar entrar num arquivo.

Todas as saídas desta aula foram colhidas no Prompt de Comando de um Windows em português, na pasta de teste C:\Users\ana\guia-cmd-teste. Nela já existiam, entre outros, os arquivos notas.txt, relatorio.txt, agenda.txt e rascunho.tmp e as pastas fotos, docs, backup e lixeira. No seu computador, pratique numa pasta de teste parecida, não na raiz do disco.

O cd /d para outra unidade não foi colhido: sairia da pasta de teste. A aula explica o interruptor com o exemplo da própria pasta.

A ideia: atravessar a porta

A pasta atual é o cômodo em que você está. cd fotos é atravessar a porta e entrar no quarto das fotos. cd .. é voltar para o corredor. O prompt, na porta, troca a plaquinha toda vez que você anda. Sem destino, o cd só lê a plaquinha e mostra o caminho.

1. Onde estou? cd sem argumento

Na pasta de teste, o cd sozinho respondeu o caminho completo:

C:\Users\ana\guia-cmd-teste>cd
C:\Users\ana\guia-cmd-teste

C:\Users\ana\guia-cmd-teste>

É o mesmo caminho que já estava no prompt. Útil quando o prompt está curto, ou quando você quer gravar o caminho num arquivo.

2. Entrando e subindo

No laboratório, cada comando começa de novo na pasta de teste. Por isso as linhas abaixo juntam o cd de destino e, na mesma linha, um cd sem argumento para mostrar aonde se chegou. O & roda o segundo pedido depois do primeiro.

Entrando em fotos:

C:\Users\ana\guia-cmd-teste>cd fotos & cd
C:\Users\ana\guia-cmd-teste\fotos

C:\Users\ana\guia-cmd-teste>

Entrando e subindo de volta com ..:

C:\Users\ana\guia-cmd-teste>cd fotos & cd .. & cd
C:\Users\ana\guia-cmd-teste

C:\Users\ana\guia-cmd-teste>

O atalho fotos\.. também volta para a pasta de teste, porque “fotos, e depois a pasta de cima” é o mesmo lugar:

C:\Users\ana\guia-cmd-teste>cd fotos\.. & cd
C:\Users\ana\guia-cmd-teste

C:\Users\ana\guia-cmd-teste>

3. O interruptor /d e o sinônimo chdir

A chave /d (de drive, “unidade”) deixa o cd trocar também de disco — por exemplo, de C: para D:. Sair da pasta de teste não foi colhido. O que o laboratório fez foi apontar o /d para a própria pasta de teste, e o cd confirmou o caminho:

C:\Users\ana\guia-cmd-teste>cd /d C:\Users\ana\guia-cmd-teste & cd
C:\Users\ana\guia-cmd-teste

C:\Users\ana\guia-cmd-teste>

O chdir é o mesmo comando, com outro nome. Sem argumento, também só mostra a pasta atual:

C:\Users\ana\guia-cmd-teste>chdir
C:\Users\ana\guia-cmd-teste

C:\Users\ana\guia-cmd-teste>

Formas diferentes de mudar de pasta

FormaQuando usar
cdPara perguntar a pasta atual, sem mudar nada.
cd fotosPara entrar numa subpasta, pelo nome relativo.
cd ..Para subir um nível, até a pasta-mãe.
cd /d C:\Users\ana\guia-cmd-testeQuando precisa também trocar de disco; nesta aula, só como exemplo na própria pasta de teste.
chdirO mesmo que cd, se você encontrar esse nome num texto antigo.

Quando dá errado

Uma pasta que não existe

O cd pasta-nao-existe devolveu esta mensagem, exatamente assim:

C:\Users\ana\guia-cmd-teste>cd pasta-nao-existe
O sistema não pode encontrar o caminho especificado.

C:\Users\ana\guia-cmd-teste>
Tentar entrar num arquivo

notas.txt é um arquivo, não uma pasta. O cmd respondeu:

C:\Users\ana\guia-cmd-teste>cd notas.txt
O nome do diretório é inválido.

C:\Users\ana\guia-cmd-teste>

Resumo

  • cd sem argumento mostra a pasta atual; com um nome, entra nessa pasta.
  • cd .. sobe um nível. chdir é o mesmo comando.
  • cd /d também pode trocar de disco; nesta aula, só foi colhido apontando para a própria pasta de teste.
  • Pasta inexistente e arquivo no lugar de pasta devolvem mensagens reais, que não se traduzem.
