goto e Rótulos

Um rótulo é um marco no script: uma linha que começa com :, como :fim. O goto pula a execução para esse marco. Nesta aula você vê o decide.bat, que usa goto e rótulos, e o conta.bat, um laço com contador que escreve Volta 1 até Volta 3 e depois Acabou. O goto :eof fica no texto: a coleta está no chama.bat da aula do call.

Você vai aprender
  • Os rótulos :nome e o goto que pula para eles, no decide.bat.
  • O goto :eof, só em texto aqui: ele encerra o script (ou o pedaço chamado por call :rótulo). A coleta está no chama.bat da aula do call.
  • Um laço feito com goto e um contador que em algum momento termina, no conta.bat: Volta 1, Volta 2, Volta 3 e Acabou.

A ideia: um pulo até o marco

Em vez de seguir linha a linha até o fim, o script pode pular para um pedaço com nome. O rótulo é a placa (:semparam, :fim). O goto é o pulo.

1. Rótulos e goto no decide.bat

O arquivo que a coleta deixou na pasta de teste tem estas linhas:

@echo off
if "%~1"=="" goto semparam
echo Você passou: %1
goto fim
:semparam
echo Nenhum parâmetro.
:fim
echo Fim.

Se você não passa nenhuma palavra, o script pula para :semparam. Se você passa alguma, ele mostra o parâmetro e vai para :fim. Nos dois caminhos, a última linha é o recado de fim. A coleta rodou o type e as duas execuções:

2. goto :eof, só em texto nesta aula

O :eof é um rótulo especial: “fim do arquivo” (end of file). O goto :eof encerra o script, ou o pedaço que um call :rótulo estava executando, e devolve a execução. Neste lote, isso aparece no chama.bat, coletado na aula do call. Aqui não repetimos essa caixa nem inventamos outra.

3. Laço com goto e contador: o conta.bat

Dá para montar um laço pulando de volta para o mesmo rótulo. Esse laço precisa de um contador (uma variável que cresce ou diminui e, em algum momento, faz o script seguir em frente). Sem isso, o pulo não termina. O conta.bat da coleta do lote 2b faz exatamente isso, com a variável GUIA_C. Os comentários rem e :: desse arquivo também aparecem na aula de arquivos .bat.

C:\Users\ana\guia-cmd-teste>type conta.bat
@echo off
rem conta ate 3 com goto
:: comentario com dois-pontos duplos
set /a GUIA_C=0
:volta
set /a GUIA_C+=1
echo Volta %GUIA_C%
if %GUIA_C% GEQ 3 goto fim
goto volta
:fim
echo Acabou

C:\Users\ana\guia-cmd-teste>

A cada volta, o script soma 1 em GUIA_C, escreve Volta e o número, e só vai para :fim quando o contador chega a 3. A saída real foi esta:

C:\Users\ana\guia-cmd-teste>conta.bat
Volta 1
Volta 2
Volta 3
Acabou

C:\Users\ana\guia-cmd-teste>

O outro arquivo desta seção, o soma.bat, também foi coletado no lote 2. Ele soma de 1 a 5 com for /l e %%i (e lista os *.txt com %%f), não com goto. É o exemplo de %%i dentro de um .bat de que a aula do for fala:

@echo off
setlocal
set /a total=0
for /l %%i in (1,1,5) do set /a total+=%%i
echo Soma de 1 a 5: %total%
for %%f in (*.txt) do echo arquivo: %%f
endlocal
C:\Users\ana\guia-cmd-teste>type soma.bat
@echo off

for /l %%i in (1,1,5) do set /a total+=%%i
echo Soma de 1 a 5: %total%
for %%f in (*.txt) do echo arquivo: %%f
endlocal

Formas diferentes de pular

FormaQuando usar
:nomePara marcar um ponto no script.
goto nomePara pular para esse marco, como no decide.bat.
goto :eofPara encerrar o script ou o pedaço chamado por call :rótulo. Coletado na aula do call.
laço com goto e contadorComo no conta.bat: o GUIA_C cresce e, no 3, o script vai para :fim.

Quando dá errado

Um rótulo que não existe

O semrotulo.bat, que faz goto rotulo-que-nao-existe, foi coletado na aula do call. A mensagem de erro real está lá. Nesta página não inventamos essa caixa.

Resumo

  • Um rótulo começa com :. O goto pula para esse marco, como no decide.bat.
  • O goto :eof encerra o script ou o pedaço de um call :rótulo; a coleta está na aula do call.
  • Um laço de goto precisa de contador. No conta.bat, a saída real foi Volta 1, Volta 2, Volta 3 e Acabou. O soma.bat conta com for /l, não com goto.
