Esperando (timeout)

O timeout espera alguns segundos antes de seguir. Nesta aula as saídas são as da coleta do lote 2e. O invólucro dessa coleta sempre redireciona a entrada com < nul, e o timeout recusou isso: os dois pedidos (/t 1 /nobreak e /t 1) devolveram o mesmo erro de redirecionamento. Essa é a pegadinha da aula. A contagem normal, sem redirecionar a entrada, não foi coletada e fica só no texto, sem caixa de saída.

Você vai aprender
  • Que timeout /t 1 /nobreak e timeout /t 1, nesta coleta com a entrada redirecionada, devolveram ERRO: não há suporte para o redirecionamento de entrada; saindo do processo imediatamente.
  • Que timeout /t abc devolveu o erro real de valor inválido, com o intervalo de -1 a 99999.
  • Que a contagem normal (sem < nul) não tem caixa nesta aula: a coleta não registrou essa saída.

Todas as saídas desta aula foram colhidas no Prompt de Comando de um Windows em português, na pasta de teste C:\Users\ana\guia-cmd-teste. No seu computador, pratique numa pasta de teste parecida, não na raiz do disco. Cada caixa traz a saída real, com a linha em branco que o Prompt deixa antes do próximo prompt. Não inventamos nem traduzimos mensagem de erro. A aula de redirecionamento mostra o <; aqui o foco é o que o timeout faz quando a entrada vem de nul.

A ideia: uma pausa no script

Às vezes o script precisa esperar um pouco — por exemplo, antes de o próximo pedido rodar. O timeout /t 1 é essa pausa de um segundo. Na coleta, porém, a entrada foi redirecionada, e o que apareceu não foi a pausa: foi um erro. Vale entender essa pegadinha antes de usar o comando no seu Prompt.

1. A pegadinha: entrada redirecionada

O invólucro da coleta sempre manda < nul junto com o pedido. Na tela do Prompt, a linha do comando saiu sem esse redirecionamento, mas a entrada veio de nul do mesmo jeito. Os dois pedidos recusaram e saíram na hora:

C:\Users\ana\guia-cmd-teste>timeout /t 1 /nobreak
ERRO: não há suporte para o redirecionamento de entrada; saindo do processo
      imediatamente.

C:\Users\ana\guia-cmd-teste>
C:\Users\ana\guia-cmd-teste>timeout /t 1
ERRO: não há suporte para o redirecionamento de entrada; saindo do processo
      imediatamente.

C:\Users\ana\guia-cmd-teste>
/t 1
o tempo da pausa, em segundos, que nesta coleta nem chegou a contar.
/nobreak
no uso normal, impede que uma tecla interrompa a espera. Aqui, com a entrada redirecionada, o pedido também saiu com o mesmo erro.

Para reproduzir essa pegadinha no seu Prompt, rode o pedido com < nul no fim: é isso que a coleta fez, e é isso que as missões pedem.

2. A contagem normal, só em texto

Sem redirecionar a entrada, o timeout /t 1 espera o número de segundos (e, no uso comum, mostra uma contagem; com /nobreak, uma tecla não cancela a espera). Essa saída normal não foi coletada neste lote, porque o invólucro sempre manda < nul. Esta aula não inventa a caixa. Fica só nesta explicação.

Quando dá errado

Um valor que não é número

O pedido timeout /t abc não é um tempo válido. A coleta devolveu este erro, com o intervalo aceito de -1 a 99999:

C:\Users\ana\guia-cmd-teste>timeout /t abc
ERRO: foi especificado um valor inválido para o tempo limite (/T).
      O intervalo válido vai de -1 a 99999.

C:\Users\ana\guia-cmd-teste>

Formas diferentes de usar o timeout

FormaQuando usar
timeout /t 1Para esperar um segundo, sem redirecionar a entrada. A contagem normal fica só no texto nesta aula.
timeout /t 1 /nobreakA mesma espera, sem deixar uma tecla cancelar. Só no texto, no uso normal.
timeout /t 1 < nul ou timeout /t 1 /nobreak < nulPara reproduzir a pegadinha da coleta: o erro de redirecionamento de entrada.
timeout /t abcNão use: o valor é inválido, e a coleta mostrou o erro com o intervalo de -1 a 99999.

Referência rápida

Você digitaO que faz
timeout /t 1 /nobreak < nulNesta coleta (e com < nul), devolve ERRO: não há suporte para o redirecionamento de entrada.
timeout /t 1 < nulO mesmo erro, sem o /nobreak.
timeout /t abcDevolve o erro de valor inválido para o /T.

Resumo

  • Nesta coleta, timeout /t 1 /nobreak e timeout /t 1 devolveram ERRO: não há suporte para o redirecionamento de entrada; saindo do processo imediatamente. A causa foi o < nul do invólucro.

  • O timeout /t abc mostrou o erro de valor inválido, com o intervalo de -1 a 99999.
