Escrevendo na Tela (echo)

O echo pede ao computador que escreva um texto. É o “olá” das mensagens na tela e, com um >, também o jeito mais simples de gravar esse texto num arquivo. Nesta aula você vê o eco na tela, a linha em branco, a gravação em arquivo — e deixa o echo off só na explicação, sem caixa de saída.

Você vai aprender
  • O echo texto, que escreve o texto na tela.
  • O echo. (com o ponto encostado), que pula uma linha em branco.
  • O que echo on e echo off fazem no Prompt aberto — só em texto, sem saída colhida.
  • A gravar e a acrescentar texto num arquivo com > e >>.
  • Os erros reais de redirecionar para uma pasta e para um caminho que não existe.

Todas as saídas desta aula foram colhidas no Prompt de Comando de um Windows em português, na pasta de teste C:\Users\ana\guia-cmd-teste. Nela já existiam, entre outros, os arquivos notas.txt, relatorio.txt, agenda.txt e rascunho.tmp e as pastas fotos, docs, backup e lixeira. No seu computador, pratique numa pasta de teste parecida, não na raiz do disco.

A ideia: um megafone

O echo é um megafone: o que você coloca na frente dele é o que aparece na tela. Com um >, o megafone aponta para um arquivo em vez da tela.

1. Escrever na tela

O pedido echo Olá, turma devolveu exatamente o texto, sem a palavra echo:

C:\Users\ana\guia-cmd-teste>echo Olá, turma
Olá, turma

C:\Users\ana\guia-cmd-teste>
echo
o comando: “escreva isto”.
Olá, turma
o texto que você quer ver.

2. Uma linha em branco: echo.

O ponto encostado no echo é proposital: pede uma linha vazia. A saída colhida foi isso — uma linha em branco — e depois o prompt voltou:

C:\Users\ana\guia-cmd-teste>echo.


C:\Users\ana\guia-cmd-teste>

3. echo on e echo off, só em texto

No Prompt aberto, o echo off esconde a repetição dos próprios comandos: o que você digitou deixa de ser “ecoado” antes da resposta. O echo on liga o eco de novo. Isso é especialmente útil dentro de um arquivo .bat, no Nível 3.

Via cmd /c, o efeito interativo (o prompt “sumir” ou o comando deixar de se repetir) não aparece. Por isso esta aula explica o echo off e o echo on só em texto, sem caixa de saída, como combinado na coleta.

4. Gravar num arquivo: > e >>

O > manda o texto para um arquivo, em vez da tela. O comando em si não imprime nada. Depois, o type mostra o que ficou gravado:

C:\Users\ana\guia-cmd-teste>echo Olá, turma > saudacao.txt

C:\Users\ana\guia-cmd-teste>type saudacao.txt
Olá, turma 

C:\Users\ana\guia-cmd-teste>

Olhe com cuidado a linha do type: o arquivo ficou com Olá, turma , com um espaço no fim. Esse espaço é o que estava no comando, entre a palavra turma e o >. O echo grava esse espaço. Na aula de redirecionamento a gente volta a esse detalhe.

O >> acrescenta no fim, sem apagar o que já existia. Depois de mais uma linha, de um echo. (linha vazia) e de um fim, o arquivo ficou assim:

C:\Users\ana\guia-cmd-teste>type saudacao.txt
Olá, turma 
segunda linha 
 
fim 

C:\Users\ana\guia-cmd-teste>

Formas diferentes de usar o echo

FormaQuando usar
echo Olá, turmaPara escrever o texto na tela.
echo.Para pular uma linha em branco (o ponto encostado é parte do comando).
echo on / echo offNo Prompt aberto ou num .bat, para mostrar ou esconder os próprios comandos. Nesta aula, só em texto.
echo texto > arquivo.txtPara gravar o texto num arquivo, substituindo o conteúdo anterior.
echo texto >> arquivo.txtPara acrescentar o texto no fim do arquivo.

Quando dá errado

Redirecionar para uma pasta

fotos é uma pasta. O pedido echo texto > fotos devolveu:

C:\Users\ana\guia-cmd-teste>echo texto > fotos
Acesso negado.

C:\Users\ana\guia-cmd-teste>
Um caminho que não existe

Com echo texto > pasta-nao-existe\x.txt, a mensagem foi esta:

C:\Users\ana\guia-cmd-teste>echo texto > pasta-nao-existe\x.txt
O sistema não pode encontrar o caminho especificado.

C:\Users\ana\guia-cmd-teste>

Referência rápida

Você digitaO que faz
echo textoEscreve o texto na tela.
echo.Escreve uma linha em branco.
echo off / echo onDesliga ou liga o eco dos comandos, no Prompt aberto. Sem saída colhida nesta aula.
echo texto > arq.txtGrava o texto no arquivo (e também o espaço que vier antes do >).
echo texto >> arq.txtAcrescenta o texto no fim do arquivo.

Resumo

  • echo texto escreve o texto na tela. echo. pula uma linha em branco.
  • echo off e echo on ligam ou desligam o eco dos comandos no Prompt aberto; nesta aula, isso fica só na explicação, sem saída colhida.
  • > grava num arquivo (e leva o espaço que vier antes do símbolo); >> acrescenta no fim.
  • Redirecionar para uma pasta ou para um caminho inexistente devolve mensagens reais, que não se traduzem.
