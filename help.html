A Ajuda (help e /?)

Quando você esquece uma chave ou quer confirmar o que um comando faz, o próprio cmd explica. O help e o /? mostram o texto oficial do Windows, em português neste laboratório. Nesta aula você lê essa ajuda de verdade e vê o que acontece quando o nome do comando não existe.

Você vai aprender
  • O help comando e o comando /?, que mostram a descrição oficial.
  • Que os dois jeitos, no laboratório, devolveram o mesmo texto para o dir e para o cd.
  • O echo /?, uma ajuda curta e completa.
  • Os erros reais de um comando que a ajuda não conhece e de um nome que o cmd não reconhece.

Todas as saídas desta aula foram colhidas no Prompt de Comando de um Windows em português, na pasta de teste C:\Users\ana\guia-cmd-teste. Nela já existiam, entre outros, os arquivos notas.txt, relatorio.txt, agenda.txt e rascunho.tmp e as pastas fotos, docs, backup e lixeira. No seu computador, pratique numa pasta de teste parecida, não na raiz do disco.

O help sozinho lista todos os comandos internos; a saída é longa (mais de cem linhas no laboratório). Aqui usamos a ajuda de um comando de cada vez, que é o jeito mais útil no dia a dia. No Prompt interativo, o help às vezes passa pelo MORE; se a tela pausar, a tecla de espaço continua.

A ideia: o folheto que vem na caixa

Cada comando traz um folheto de instruções. O help e o /? abrem esse folheto. Ele está na língua do Windows instalado — aqui, em português — e a gente não traduz o texto oficial.

1. help dir e dir /?

Os dois pedidos devolveram o mesmo texto no laboratório. Esta é a saída real do help dir:

C:\Users\ana\guia-cmd-teste>help dir
Exibe uma lista de arquivos e subdiretórios em um diretório.

DIR [drive:][path][filename] [/A[[:]attributes]] [/B] [/C] [/D] [/L] [/N]
  [/O[[:]sortorder]] [/P] [/Q] [/R] [/S] [/T[[:]timefield]] [/W] [/X] [/4]

  [drive:][path][filename]
              Especifica a unidade, o diretório e/ou arquivos a serem listados.

  /A          Exibe arquivos com atributos especificados.
  atributos   D  Diretórios              R  Arquivos somente leitura
               H  Arquivos ocultos        A  Arquivos prontos para arquivamento
               S  Arquivos de sistema     I  Arquivos sem conteúdo indexado
               L  Pontos de nova análise             O  Arquivos offline
               -  Prefixo significando negação
  /B          Usa formatação básica (sem informações de cabeçalho ou resumo).
  /C          Exibe o separador de milhar em tamanhos de arquivos. É o
              padrão.  Use /-C para desabilitar a exibição do separador.
  /D          O mesmo que amplo, mas os arquivos são classificados na lista por coluna.
  /L          Usa letras minúsculas.
  /N          Novo formato de lista longo onde os nomes de arquivos estão à extrema direita.
  /O          Lista por arquivos na ordem classificada.
  sortorder    N  Por nome (alfabético)       S  Por tamanho (menor primeiro)
               E  Por extensão (alfabética)  D  Por data/hora (mais antiga primeiro)
               G  Grupo de diretórios primeiro  -  Prefixo para inverter a ordem
  /P          Pausa após cada tela de informações.
  /Q          Exibe o proprietário do arquivo.
  /R          Exibe fluxos de dados alternados do arquivo.
  /S          Exibe os arquivos no diretório especificado e em todos os subdiretórios.
  /T          Controla qual campo de tempo é exibido ou usado na classificação
  timefield  C  Criação
              A  Último Acesso
              W  Última Gravação
  /W          Usa o formato de lista amplo.
  /X          Exibe os nomes curtos gerados para nomes de arquivos
              diferentes do formato 8.3. O formato é /N com o nome curto
              inserido antes do nome longo. Se nenhum nome curto estiver
              presente, serão exibidos espaços no seu lugar.
  /4          Exibe anos de quatro dígitos

As opções podem estar predefinidas na variável de ambiente DIRCMD.
Substituir nas opções predefinidas ao prefixar qualquer opção com - (hífen)--por exemplo, /-W.

C:\Users\ana\guia-cmd-teste>

O dir /? foi idêntico, palavra por palavra. O mesmo aconteceu com help cd e cd /?. Use o jeito que preferir: uns lembram o /? no fim do comando; outros preferem o help na frente.

2. Uma ajuda curta: echo /?

A do echo cabe numa olhada:

C:\Users\ana\guia-cmd-teste>echo /?
Exibe mensagens ou ativa ou desativa o eco de comando.

  ECHO [ON | OFF]
  ECHO [message]

Digite ECHO sem parâmetros para exibir a configuração do eco atual.

C:\Users\ana\guia-cmd-teste>

Formas diferentes de pedir ajuda

FormaQuando usar
help dirPara ler a descrição oficial do dir.
dir /?O mesmo texto, pedido no próprio comando. No laboratório, idêntico ao help dir.
helpPara ver a lista de todos os comandos internos (saída longa).

Quando dá errado

Um nome que a ajuda não conhece

O help comandoinexistente devolveu esta frase, exatamente assim:

C:\Users\ana\guia-cmd-teste>help comandoinexistente
O utilitário de ajuda não dá suporte a este comando. Experimente usar "comandoinexistente /?".

C:\Users\ana\guia-cmd-teste>
Um nome que o cmd não reconhece

Digitando o nome sozinho, sem help, o Prompt respondeu em duas linhas:

C:\Users\ana\guia-cmd-teste>comandoinexistente
'comandoinexistente' não é reconhecido como um comando interno
ou externo, um programa operável ou um arquivo em lotes.

C:\Users\ana\guia-cmd-teste>

Referência rápida

Você digitaO que faz
help comandoMostra a ajuda oficial daquele comando.
comando /?O mesmo, pedido no próprio comando.
helpLista os comandos internos (saída longa).

Resumo

  • help comando e comando /? mostram a ajuda oficial. No laboratório, os dois jeitos vieram iguais para o dir e para o cd.
  • O texto da ajuda não se traduz: entra como o Windows escreveu.
  • Um nome desconhecido devolve mensagens reais, diferentes no help e no Prompt sozinho.
