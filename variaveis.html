Variáveis (%VAR% e set)

Uma variável é um nome que guarda um valor, para você reusar depois. No Prompt, quem cria e muda esse nome é o set, e quem lê o valor é o %nome%. Nesta aula só entram variáveis criadas por você, com o prefixo GUIA_. Não listamos o set sozinho, nem pedimos %PATH%, %USERNAME%, %USERPROFILE% ou %COMPUTERNAME%: essas saídas trariam dados do computador, e não pertencem à aula.

Você vai aprender
  • O set GUIA_NOME=Ana, sem espaço antes do =, e a leitura com %GUIA_NOME%.
  • O set GUIA_ (com o prefixo), que lista só as variáveis da aula, nunca o set sem filtro.
  • O set /a, que faz conta.
  • O set /p, só em texto: ele espera você digitar, e por isso não tem caixa de saída nesta aula.
Saída a coletar. Estas aulas do lote 2 já têm a explicação, os exercícios e as missões com o código; as respostas do Prompt só entram quando a Mira liberar o arquivo anonimizado em _saidas-anon/. Não complete as caixas de memória e não traduza mensagem de erro.

Quando as saídas reais chegarem, elas terão sido colhidas no Prompt de Comando de um Windows em português, na pasta de teste C:\Users\ana\guia-cmd-teste. No seu computador, pratique numa pasta de teste parecida, não na raiz do disco. Nada nesta aula foi inventado: cada caixa de terminal ainda mostra o placeholder « saída a coletar », que não é resposta do cmd.

A ideia: uma caixinha com etiqueta

Pense numa caixinha com uma etiqueta. O set GUIA_NOME=Ana cola a etiqueta GUIA_NOME e coloca Ana dentro. O %GUIA_NOME% é o pedido: “me mostre o que tem nessa caixinha”.

1. Criar e ler, sem espaço antes do =

O nome fica encostado no =, e o valor também. Um espaço antes do = faria o Prompt procurar um nome diferente, com um espaço no fim — e a variável que você queria não nasceria. A coleta usou o jeito certo:

C:\Users\ana\guia-cmd-teste>set GUIA_NOME=Ana & echo %GUIA_NOME%

2. Listar só as variáveis da aula

O set sozinho listaria muita coisa do sistema, inclusive caminhos do perfil. Esta aula nunca pede isso. O jeito seguro é filtrar pelo prefixo GUIA_:

C:\Users\ana\guia-cmd-teste>set "GUIA_NOME=Ana" & set GUIA_

3. Contas: set /a

O /a pede uma expressão aritmética. A coleta tem uma conta simples, uma com parênteses e duas que guardam o resultado em GUIA_X (estas últimas, de novo, com /v:on, para o echo na mesma linha ver o valor novo):

C:\Users\ana\guia-cmd-teste>set /a 5+3

« saída a coletar »

C:\Users\ana\guia-cmd-teste>
C:\Users\ana\guia-cmd-teste>set /a "(10+2)*3"

« saída a coletar »

C:\Users\ana\guia-cmd-teste>
C:\Users\ana\guia-cmd-teste>set /a GUIA_X=10*2 >nul & echo GUIA_X vale !GUIA_X!

« saída a coletar »

C:\Users\ana\guia-cmd-teste>
C:\Users\ana\guia-cmd-teste>set /a GUIA_X=7 >nul & set /a GUIA_X+=5 >nul & echo !GUIA_X!

C:\Users\ana\guia-cmd-teste>

4. set /p, só em texto

O set /p GUIA_R=Seu nome: mostra um recado e espera você digitar. É interativo. Nesta aula ele aparece só nesta explicação, sem caixa de terminal: uma coleta automática não substitui a sua resposta, e nós não inventamos a saída.

Formas diferentes de usar o set

FormaQuando usar
set GUIA_NOME=AnaPara criar ou mudar a variável, com o = encostado no nome.
echo %GUIA_NOME%Para ler o valor. Na mesma linha de um set, a coleta também usou !GUIA_NOME! com /v:on.
set GUIA_Para listar só as variáveis que começam com GUIA_, nunca o set sozinho.
set /a 5+3Para fazer conta. O resultado pode ir para uma variável, como GUIA_X.
set /p GUIA_R=Seu nome: Para perguntar e esperar a digitação. Só em texto nesta aula.

Quando dá errado

Uma variável que você apagou

C:\Users\ana\guia-cmd-teste>set "GUIA_NOME=Ana" & set "GUIA_NOME=" & set GUIA_NOME

Resumo

  • set NOME=valor cria a variável, com o = encostado no nome. %NOME% lê o valor.
  • Só usamos variáveis da aula, com o prefixo GUIA_. Nunca o set sozinho, nem %PATH%, %USERNAME%, %USERPROFILE% ou %COMPUTERNAME%.
  • set /a faz conta. set /p pergunta e espera: nesta aula, só em texto.
  • As saídas reais ainda estão a coletar.
