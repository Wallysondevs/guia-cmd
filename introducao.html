O que é o Prompt de Comando

Antes de listar pastas ou copiar arquivos, vale entender o que é essa janela e o que significa aquela linha que termina em >. Nesta aula você vê a ideia, lê o prompt e monta o primeiro pedido com o echo.

Você vai aprender
  • O que é o Prompt de Comando, o cmd.exe que já vem no Windows.
  • O que é o prompt C:\Users\ana\guia-cmd-teste> e o que cada pedaço dele quer dizer.
  • A diferença, em uma frase, entre o cmd e o PowerShell.
  • A rodar um comando: digitar e apertar Enter.
  • O echo, que escreve um texto na tela — o primeiro pedido deste guia.

Todas as saídas desta aula foram colhidas no Prompt de Comando de um Windows em português, na pasta de teste C:\Users\ana\guia-cmd-teste. No seu computador, pratique numa pasta de teste parecida, não na raiz do disco. Cada caixa traz a saída real, com a linha em branco que o Prompt deixa antes do próximo prompt. Não inventamos nem traduzimos mensagem de erro.

A ideia: um balcão de atendimento

Pense no balcão de uma repartição. O atendente fica parado, olhando para você, até você falar o que quer. Você faz o pedido, ele resolve, entrega a resposta e volta a olhar para você, pronto para o próximo pedido.

O Prompt de Comando funciona igual. A linha que termina em > é o atendente esperando: o prompt. Você digita o pedido (o comando), aperta Enter, ele mostra a resposta (a saída) e o prompt aparece de novo.

cmd e PowerShell, em uma frase

Os dois são terminais do Windows. O cmd devolve texto: uma lista, uma mensagem, uma linha. O PowerShell devolve um objeto — uma ficha com várias informações. Este guia ensina só o Prompt de Comando. Se você também quer o PowerShell, há um guia irmão, mas aqui o foco é o cmd.

1. O primeiro pedido: echo

O echo pede ao computador que escreva um texto na tela. É o “olá” deste guia: simples, visível, e já ensina o ciclo digitar → Enter → ler a resposta. O pedido echo Olá, turma devolveu exatamente o texto, sem a palavra echo:

C:\Users\ana\guia-cmd-teste>echo Olá, turma
Olá, turma

C:\Users\ana\guia-cmd-teste>
echo
o comando: “escreva isto na tela”.
Olá, turma
o texto que você quer ver.

Quando dá errado

Digitar um nome que o cmd não reconhece

Se você escrever um comando que não existe — nesta coleta, comandoinexistente —, o cmd responde com uma mensagem de erro. O mesmo tipo de aviso aparece para qualquer nome desconhecido (por exemplo, um eco sem o “h”); só muda a palavra entre aspas. A mensagem colhida, em duas linhas, foi esta:

C:\Users\ana\guia-cmd-teste>comandoinexistente
'comandoinexistente' não é reconhecido como um comando interno
ou externo, um programa operável ou um arquivo em lotes.

C:\Users\ana\guia-cmd-teste>
