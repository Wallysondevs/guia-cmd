Consultando Serviços (sc query)

O sc query consulta um serviço do Windows: lê o estado, não altera nada. Nesta coleta, o Spooler (o serviço de impressão) veio com o estado RUNNING. Um nome que não existe, servico-que-nao-existe, devolveu a FALHA 1060. Não houve sc qc nesta captura, então essa forma não entra na aula. Esta aula é só consulta: não pede para parar, iniciar ou apagar serviço.

Você vai aprender
  • O sc query Spooler, e o estado RUNNING desta coleta.
  • O find "ESTADO" na mesma consulta, para ver só essa linha.
  • A FALHA 1060 quando o serviço não existe, com a mensagem real do Prompt.

Todas as saídas desta aula foram colhidas no Prompt de Comando de um Windows em português, na pasta de teste C:\Users\ana\guia-cmd-teste. No seu computador, o Spooler pode estar em outro estado. Pratique só com sc query, sem outros subcomandos do sc.

A ideia: perguntar na recepção se o elevador está funcionando

Você não desliga o elevador: só pergunta se ele está no ar. O sc query é essa pergunta. O nome Spooler é o do serviço de impressão, um alvo estável e de leitura.

1. Consultar o Spooler

O sc query Spooler desta coleta mostrou o serviço em RUNNING. A linha do nome tem um espaço no fim, e a do estado também; entram como vieram:

C:\Users\ana\guia-cmd-teste>sc query Spooler

NOME_DO_SERVIÇO: Spooler 
    TIPO                       : 110  WIN32_OWN_PROCESS  (interactive)
    ESTADO                     : 4  RUNNING 
                                (STOPPABLE, NOT_PAUSABLE, IGNORES_SHUTDOWN)
    CÓDIGO_DE_SAÍDA_DO_WIN32   : 0  (0x0)
    CÓDIGO_DE_SAÍDA_DO_SERVIÇO : 0  (0x0)
    PONTO_DE_VERIFICAÇÃO       : 0x0
    AGUARDAR_DICA              : 0x0
C:\Users\ana\guia-cmd-teste>

Encadeando com o find "ESTADO", sobrou só esta linha (de novo com o espaço no fim):

C:\Users\ana\guia-cmd-teste>sc query Spooler | find "ESTADO"
    ESTADO                     : 4  RUNNING 
C:\Users\ana\guia-cmd-teste>

Quando dá errado

Um serviço que não existe

O sc query servico-que-nao-existe devolveu a FALHA 1060 e, depois de uma linha em branco, a mensagem abaixo, exatamente assim:

C:\Users\ana\guia-cmd-teste>sc query servico-que-nao-existe
[SC] EnumQueryServicesStatus:OpenService FALHA 1060:

O serviço especificado não existe como serviço instalado.

C:\Users\ana\guia-cmd-teste>

Formas diferentes

FormaQuando usar
sc query SpoolerPara ler o estado do serviço de impressão. Nesta coleta, RUNNING.
sc query Spooler | find "ESTADO"Para ver só a linha do estado.
sc query servico-que-nao-existePara ver a FALHA 1060 quando esse nome não existe.

Referência rápida

Você digitaO que faz
sc query nomeConsulta o estado do serviço. Só leitura.
