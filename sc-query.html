Consultando Serviços (sc query)

O sc query consulta um serviço do Windows: lê o estado, não altera nada. Nesta aula os pedidos da coleta são o Spooler (o serviço de impressão, que existe no Windows) e um nome que não existe, servico-que-nao-existe. A saída real ainda está a coletar. Se o nome do computador aparecer na captura, a Mira trata isso na anonimização — não inventamos essa linha.

Você vai aprender
  • O sc query Spooler, só para ler o estado do serviço.
  • O sc query servico-que-nao-existe, e a mensagem real quando esse serviço não existe (ainda a coletar).
  • Que esta aula é só consulta: não pede para parar, iniciar ou apagar serviço.
Saída a coletar. A coleta deste lote 3, quando a Mira anonimizar, entra em _saidas-anon/cmd-lote3*.txt. Enquanto esse arquivo não chega, as caixas ficam com o placeholder « saída a coletar ». Não inventamos e não traduzimos mensagem de erro.

Quando as saídas reais chegarem, elas terão sido colhidas no Prompt de Comando de um Windows em português, na pasta de teste C:\Users\ana\guia-cmd-teste, com revisão da Mira se o nome da máquina aparecer. No seu computador, pratique só com sc query, sem outros subcomandos do sc. Nada nesta aula foi inventado: cada caixa ainda mostra o placeholder « saída a coletar ».

A ideia: perguntar na recepção se o elevador está funcionando

Você não desliga o elevador: só pergunta se ele está no ar. O sc query é essa pergunta. O nome Spooler é o do serviço de impressão, um alvo estável e de leitura.

1. Consultar o Spooler

O sc query Spooler deve devolver o estado desse serviço. A saída real ainda está a coletar:

C:\Users\ana\guia-cmd-teste>sc query Spooler

Quando dá errado

Um serviço que não existe

O sc query servico-que-nao-existe devolve uma mensagem de erro. A mensagem real ainda está a coletar — não inventamos nem traduzimos:

C:\Users\ana\guia-cmd-teste>sc query servico-que-nao-existe

« saída a coletar »

C:\Users\ana\guia-cmd-teste>
