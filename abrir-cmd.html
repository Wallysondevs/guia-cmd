Abrindo o Prompt de Comando

Antes de listar pastas ou copiar arquivos, você precisa abrir a janela e reconhecer a linha que espera o seu pedido. Esta aula é só de texto: não há comando para colher no laboratório. O que importa é chegar no cmd e saber ler o prompt.

Você vai aprender
  • O que é o cmd.exe, o Prompt de Comando que já vem no Windows.
  • Quatro jeitos comuns de abrir essa janela.
  • A ler o prompt no formato C:\Users\ana\guia-cmd-teste>.
  • A diferença, no olho, entre o prompt do cmd e o do PowerShell.

No restante do guia, a usuária fictícia é a ana, o computador é o NOTEBOOK e a pasta de teste é C:\Users\ana\guia-cmd-teste. No seu PC, o nome no meio do caminho será o seu, e está tudo bem.

A ideia: uma janela que espera um pedido

O Prompt de Comando é uma janela do Windows em que você conversa com o computador por escrito. Ela não faz nada sozinha: fica com o cursor piscando, no fim de uma linha que termina em >, até você digitar um comando e apertar Enter.

1. Quatro jeitos de abrir o Prompt

Qualquer um destes abre o cmd.exe. Use o que for mais confortável no seu dia a dia.

  1. Pelo menu Iniciar. Clique em Iniciar, digite cmd ou “Prompt de Comando” e abra o aplicativo Prompt de Comando. Evite abrir o PowerShell por engano: o nome na lista é outro.
  2. Pelo Executar. Aperte Win+R, digite cmd e aperte Enter.
  3. Pelo Explorador de Arquivos. Na barra de endereço de uma pasta, digite cmd e aperte Enter. O Prompt já abre nessa pasta — útil quando você já está no lugar certo.
  4. Pelo Terminal do Windows. Se você usa o Terminal do Windows, abra uma aba nova e escolha Prompt de Comando (não “PowerShell”). O perfil aparece no menu de abas.
Não precisa de administrador

Para as aulas deste nível, abra o Prompt como usuário comum. A opção “Executar como administrador” fica para o que realmente exigir permissão, mais adiante, e nunca é o padrão deste guia.

2. Lendo o prompt

Quando a janela abre, a linha que espera você tem este formato (no padrão deste guia):

C:\Users\ana\guia-cmd-teste>

Isto não é a saída de um comando colhido no laboratório: é o formato do prompt, com a pasta de teste da Ana. Os pedaços são estes:

C:
o disco em que você está. No Windows, o disco principal quase sempre se chama C:.
\Users\ana\guia-cmd-teste
a pasta atual. Neste guia, a pasta de teste da usuária fictícia ana.
>
o sinal de que o cmd está esperando o próximo comando.

Depois do > você digita o pedido e aperta Enter. A resposta aparece embaixo. Em seguida o prompt volta — no Prompt de Comando de verdade, com uma linha em branco entre a saída e essa nova linha que espera você.

Quando dá errado

Abrir o PowerShell achando que é o cmd

Os dois são terminais, e o Windows às vezes oferece o PowerShell no mesmo canto. A diferença aparece no prompt: o do Prompt de Comando começa direto no caminho, como C:\Users\ana\guia-cmd-teste>. O do PowerShell vem com PS na frente, como PS C:\Users\ana>. Se você vir o PS, fechou no programa errado para este guia: abra de novo o Prompt de Comando.

Resumo

  • O Prompt de Comando é o cmd.exe, o terminal clássico do Windows.
  • Você pode abri-lo pelo Iniciar, por Win+R, pela barra de endereço do Explorador ou pelo Terminal do Windows.
  • O prompt deste guia tem o formato C:\Users\ana\guia-cmd-teste>: disco, pasta atual e o > esperando você.
  • Se aparecer PS na frente, você está no PowerShell, não neste guia.
  • Esta aula não tem saída colhida no laboratório: o próximo passo é rodar o primeiro comando, o dir.
