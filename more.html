Página a Página (more)

Uma saída longa sobe a tela e as primeiras linhas somem. O more mostra o texto página a página e espera você pedir o próximo pedaço (em geral, com a barra de espaço). Se o arquivo é curto, ele pode mostrar tudo de uma vez e encerrar — foi o que aconteceu com notas.txt no laboratório. As saídas abaixo são as da coleta; o more não chegou a pausar nestes pedidos curtos.

Você vai aprender
  • O more arquivo, que mostra o arquivo uma tela de cada vez (ou de uma vez, se couber).
  • O more +n, que começa a partir de uma linha.
  • O uso com o pipe, como type nomes.txt | sort | more.
  • A mensagem real quando o arquivo não existe.

Todas as saídas desta aula foram colhidas no Prompt de Comando de um Windows em português, na pasta de teste C:\Users\ana\guia-cmd-teste. Nela, neste lote, já existiam, entre outros, os arquivos notas.txt, relatorio.txt, agenda.txt, nomes.txt, log.txt e rascunho.tmp, o oculto um-oculto.txt e as pastas fotos, docs, backup e lixeira. No seu computador, pratique numa pasta de teste parecida, não na raiz do disco.

A ideia: um livro com clipes

Em vez de jogar todas as páginas na mesa de uma vez, o more vira um clipe por vez. Se o texto é curto, ele mostra tudo e o prompt volta, como no notas.txt desta coleta.

1. Um arquivo página a página

O more notas.txt mostrou o conteúdo inteiro (o arquivo é curto) e encerrou:

C:\Users\ana\guia-cmd-teste>more notas.txt
Lista de compras
- pão
- leite
- café

C:\Users\ana\guia-cmd-teste>

O more +2 log.txt começou a partir da segunda linha, pulando as anteriores. A saída real foi esta:

C:\Users\ana\guia-cmd-teste>more +2 log.txt
08:10 OK nova tentativa
08:15 ERRO arquivo travado
08:20 OK backup concluido

C:\Users\ana\guia-cmd-teste>

2. A saída de outro comando

Nesta coleta não entrou o dir /s | more (a caixa dele ficaria a coletar). Entrou, na página do pipe, o pedido type nomes.txt | sort | more, que mostrou os nomes já ordenados. Como o texto é curto, o more de novo não pausou; a saída real foi esta:

C:\Users\ana\guia-cmd-teste>type nomes.txt | sort | more
Ana
ana paula
bruno
Carla
Diego

C:\Users\ana\guia-cmd-teste>

Formas diferentes de usar o more

FormaQuando usar
more notas.txtPara ler um arquivo página a página (ou de uma vez, se couber na tela).
more +2 log.txtPara começar a partir de uma linha.
type nomes.txt | sort | morePara a saída de outros comandos, também página a página.

Quando dá errado

Um arquivo que não existe

O more arquivo-nao-existe.txt devolveu esta mensagem, exatamente assim:

C:\Users\ana\guia-cmd-teste>more arquivo-nao-existe.txt
Não é possível o acesso ao arquivo C:\Users\ana\guia-cmd-teste\arquivo-nao-existe.txt

C:\Users\ana\guia-cmd-teste>

Referência rápida

Você digitaO que faz
more arquivoMostra o arquivo uma página de cada vez.
more +n arquivoComeça a partir da linha n.
comando | moreMostra a saída do comando à esquerda, também página a página.

Exercícios

1. Complete o comando

Complete para ver notas.txt com o more:

notas.txt

2. Pular linhas

Complete para começar o log.txt a partir da segunda linha:

more log.txt

3. Encadear

Qual símbolo manda a saída de um comando para o more?

type nomes.txt | sort more

4. No laboratório, o more notas.txt pausou no meio?

5. Qual é a mensagem real de more arquivo-nao-existe.txt?

6. O more altera o arquivo que você pediu para ver?

Resumo

  • more arquivo mostra o texto página a página; se o arquivo é curto, pode mostrar tudo de uma vez.
  • more +n começa a partir de uma linha. comando | more faz o mesmo com a saída de outro comando.
  • A mensagem de arquivo inexistente entra exatamente como o Prompt a escreveu.
