Página a Página (more)

Uma saída longa sobe a tela e as primeiras linhas somem. O more mostra o texto página a página e espera você pedir o próximo pedaço (em geral, com a barra de espaço). Ele pode receber um arquivo ou a saída de outro comando, pelo |. As saídas reais ainda estão a coletar — e, como o more é interativo, a coleta precisa de cuidado para não travar no “pressione uma tecla”.

Você vai aprender
  • O more arquivo, que mostra o arquivo uma tela de cada vez.
  • O uso com o pipe, como dir /s | more, para a saída longa de outro comando.
  • Que o more pausa e espera uma tecla; isso não é erro, é o jeito do comando.
Saída a coletar. O PC usado na coleta está offline. Estas aulas do lote 2 já têm a explicação, os exercícios e as missões com o código; as respostas do Prompt só entram quando a Mira liberar o arquivo anonimizado em _saidas-anon/. Não complete as caixas de memória e não traduza mensagem de erro.

Quando as saídas reais chegarem, elas terão sido colhidas no Prompt de Comando de um Windows em português, na pasta de teste C:\Users\ana\guia-cmd-teste. No seu computador, pratique numa pasta de teste parecida, não na raiz do disco. Nada nesta aula foi inventado: cada caixa de terminal ainda mostra o placeholder « saída a coletar », que não é resposta do cmd.

A ideia: um livro com clipes

Em vez de jogar todas as páginas na mesa de uma vez, o more vira um clipe por vez. Você lê, aperta espaço, e vem a próxima folha. Quando acaba, o prompt volta.

1. Um arquivo página a página

Na pasta de teste, um arquivo de texto já basta para ver a ideia. Se o arquivo for curto, o more pode mostrar tudo de uma vez e encerrar; se for longo, ele pausa.

C:\Users\ana\guia-cmd-teste>more notas.txt

« saída a coletar »

C:\Users\ana\guia-cmd-teste>
more
o comando: “mostre isto uma página de cada vez”.
notas.txt
o arquivo.

2. A saída de outro comando

O dir /s pode ser comprido. Encadeado com o more, a lista aparece aos poucos:

C:\Users\ana\guia-cmd-teste>dir /s | more

« saída a coletar »

C:\Users\ana\guia-cmd-teste>

Formas diferentes de usar o more

FormaQuando usar
more notas.txtPara ler um arquivo página a página.
dir /s | morePara a saída longa de outro comando não escapar da tela.

Quando dá errado

Um arquivo que não existe

O more arquivo-nao-existe.txt devolve uma mensagem de erro. A mensagem real ainda está a coletar — não inventamos nem traduzimos.

C:\Users\ana\guia-cmd-teste>more arquivo-nao-existe.txt

« saída a coletar » — mensagem de erro real, nunca inventar

C:\Users\ana\guia-cmd-teste>

Referência rápida

Você digitaO que faz
more arquivoMostra o arquivo uma página de cada vez.
comando | moreMostra a saída do comando à esquerda, também página a página.
Espaço (no more parado)Pede a próxima página. Isso é interação, não é um comando novo.

Exercícios

1. Complete o comando

Complete para ver notas.txt página a página:

notas.txt

2. Encadear

Complete para mandar a lista longa do dir /s para o more:

dir /s more

3. A tecla

Que tecla, em geral, pede a próxima página quando o more pausa? (escreva espaço)

4. Por que o more pausa no meio da saída?

5. O more altera o arquivo que você pediu para ver?

6. Qual destas formas manda a saída de um comando para o more?

Missão: na pasta de teste, mostre notas.txt com o more. Se o comando encerrar sem pausar (arquivo curto), cole o que apareceu na tela; se ele pausar, use a barra de espaço até o prompt voltar e cole a saída.

Resumo

  • more arquivo mostra o texto página a página.
  • comando | more faz o mesmo com a saída de outro comando.
  • A pausa é o jeito do more, não um erro. As saídas reais ainda estão a coletar.
