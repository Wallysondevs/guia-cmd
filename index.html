Tutorial CMD

Aprenda a conversar com o computador por escrito no Prompt de Comando do Windows, do zero, como numa escola: cada comando é explicado pedaço por pedaço e você vê a resposta de verdade, colhida no cmd. Este guia ensina o Prompt de Comando clássico, o cmd.exe que já vem no Windows.

O que é este guia

O Prompt de Comando, o cmd, é o terminal clássico do Windows. Você digita um pedido, aperta Enter e lê a resposta em texto. Com ele dá para listar pastas, copiar e apagar arquivos, encadear comandos e escrever arquivos .bat que repetem essas tarefas sozinhos.

O guia é para quem nunca programou e nunca usou um terminal. Ele começa do zero (o que é o prompt? como se roda um comando?) e vai até os arquivos de lote e alguns comandos de rede e de sistema. Cada aula ensina um assunto só. Os exemplos acompanham a vida da Ana, no computador fictício NOTEBOOK, na pasta C:\Users\ana.

O texto está em português do Brasil. Os nomes dos comandos ficam como o próprio cmd os escreve (dir, copy, md), e a gente traduz o termo na primeira vez. As mensagens de erro do Windows não são traduzidas: aparecem exatamente como o cmd mostrou, com a explicação em português em seguida.

Como estudar

Terminal se aprende usando. Para cada aula, siga estes quatro passos:

  1. Leia com calma. Leia a ideia, a anatomia e a saída. Não pule a parte “Quando dá errado”.
  2. Mexa nos exemplos. Onde houver uma caixa Experimente, copie o comando, rode no seu Prompt de Comando e cole o que ele respondeu.
  3. Faça as missões e os exercícios. As caixas com Missão e as perguntas do fim da aula conferem se você acertou. Tente de verdade antes de abrir a solução.
  4. Repita no seu computador. Abra o Prompt de Comando e refaça os comandos no seu terminal. Este guia é só do Windows.
A regra de ouro

Ler não basta: digite cada comando. Copiar e colar ensina pouco; digitar faz você reparar em cada espaço, cada barra invertida e cada aspa. Comece aqui, pela aula O que é o Prompt de Comando.
