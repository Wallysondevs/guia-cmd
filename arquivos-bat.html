Arquivos .bat

Um arquivo .bat é uma lista de pedidos que o Prompt executa em sequência, como uma receita salva. Em vez de redigitar tudo, você chama o arquivo pelo nome. Nesta aula você vê o @echo off, a execução pelo nome, os comentários rem e :: no conta.bat da coleta, e, só em texto, como criar o arquivo e o que faz o pause.

Você vai aprender
  • O que é um arquivo .bat e como criá-lo no Bloco de Notas ou com echo > — só em texto, porque a coleta desta aula já deixou os arquivos prontos na pasta de teste e não colheu essa criação.
  • A primeira linha @echo off, que esconde a repetição dos próprios comandos.
  • Os comentários rem e ::, no conta.bat da coleta (a execução do laço fica na aula de goto).
  • A executar o arquivo pelo nome, e a diferença breve do call (a aula do call aprofunda).
  • O pause, só em texto: ele espera uma tecla, e por isso não entra na coleta automática.

A ideia: uma receita salva

Em vez de ditar cada passo na hora, você escreve os passos num arquivo e chama o arquivo pelo nome. O Prompt lê de cima para baixo. A pasta de trabalho continua sendo a pasta de teste.

1. Criar o arquivo, só em texto

No dia a dia, você pode criar o .bat no Bloco de Notas (Notepad) ou com um echo linha > ola.bat e depois echo outra >> ola.bat, sempre dentro da pasta de teste. Este lote não coletou essa criação (quem gravou os exemplos foi o roteiro, fora da aula). Por isso não há caixa de terminal aqui — só a explicação.

2. O ola.bat e o @echo off

O arquivo que a coleta deixou na pasta de teste tem estas linhas:

@echo off
echo Olá do arquivo .bat
echo Pasta atual: %CD%

O @echo off pede para o Prompt não repetir cada linha antes de executá-la. O @ na frente aplica isso já à própria linha. O echo Pasta atual: %CD% mostra a pasta corrente (na saída real, o caminho será anonimizado pela Mira; não adiantamos esse texto).

O type mostra o arquivo. Rodar ola.bat pelo nome executa a receita. O call ola.bat também chama o arquivo, e é o jeito certo de chamá-lo de dentro de outro .bat se você quiser que a execução volte — isso fica para a aula do call.

3. Comentários rem e ::

O rem e o :: servem para deixar um recado no script, que o Prompt não executa como pedido útil. Os dois aparecem no conta.bat da coleta do lote 2b. O laço com goto desse arquivo é o tema da aula de goto; aqui olhamos só os comentários, na saída real do type:

C:\Users\ana\guia-cmd-teste>type conta.bat
@echo off
rem conta ate 3 com goto
:: comentario com dois-pontos duplos
set /a GUIA_C=0
:volta
set /a GUIA_C+=1
echo Volta %GUIA_C%
if %GUIA_C% GEQ 3 goto fim
goto volta
:fim
echo Acabou

C:\Users\ana\guia-cmd-teste>

A linha rem conta ate 3 com goto é um comentário clássico. A linha :: comentario com dois-pontos duplos é o outro jeito, com dois-pontos duplos. Nenhuma das duas altera o que o script faz quando roda.

4. Palavras depois do nome

Você pode passar palavras depois do nome do arquivo. O params.bat da coleta mostra a primeira (%1), a segunda (%2), todas (%*) e o nome do script (%~n0). A aula de parâmetros aprofunda isso; aqui o importante é ver o arquivo rodar com argumentos, na pasta de teste:

@echo off
echo Primeiro: %1
echo Segundo: %2
echo Todos: %*
echo Nome do script: %~n0
C:\Users\ana\guia-cmd-teste>type params.bat

« saída a coletar »

5. O pause, só em texto

O pause escreve um recado e espera você apertar uma tecla. É interativo, então não entra na coleta automática e não tem caixa de terminal nesta aula.

Formas diferentes de usar um .bat

FormaQuando usar
Bloco de Notas ou echo >Para criar o arquivo, só na pasta de teste. Sem caixa de saída neste lote.
@echo offNo começo do .bat, para não repetir cada linha na tela.
ola.batPara executar o arquivo pelo nome, na pasta atual.
call ola.batPara chamar o arquivo e, de dentro de outro script, voltar depois. Veja a aula do call.
rem / ::Comentário no script, como no conta.bat da coleta.
pauseEspera uma tecla. Só em texto nesta aula, porque é interativo.

Quando dá errado

Um .bat que não existe

O pedido nao-existe.bat foi coletado na aula do call, não nesta. Aqui não inventamos essa mensagem de erro.

Resumo

  • Um .bat é uma receita de comandos. Você o executa pelo nome, na pasta de teste.
  • @echo off esconde a repetição das linhas. rem e :: são comentários, como no conta.bat. O pause fica só no texto, porque é interativo.
  • A criação com Bloco de Notas ou echo > também fica só no texto: a coleta já deixou os arquivos prontos.
  • As saídas reais ainda estão a coletar.
