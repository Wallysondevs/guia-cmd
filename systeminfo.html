Informações do Sistema (systeminfo)

O systeminfo lista muita informação do Windows. Nesta aula a coleta nunca pediu a saída inteira: o pedido passou pelo findstr e ficou só com o nome e a versão do sistema operacional. Esse filtro demora uns 20 segundos — não é travamento. Nesta coleta o nome foi Microsoft Windows 10 Pro for Workstations e a versão, 10.0.19045 N/A compilação 19045.

Você vai aprender
  • O systeminfo filtrado com findstr, só para o nome e a versão do sistema operacional.
  • Que este pedido demora uns 20 segundos, e isso é esperado.
  • Que, nesta coleta, o Windows foi o 10 Pro for Workstations, compilação 19045.
  • Por que esta aula não pede o systeminfo sem filtro: a saída completa traz dados demais da máquina.

Todas as saídas desta aula foram colhidas no Prompt de Comando de um Windows em português, na pasta de teste C:\Users\ana\guia-cmd-teste, na página de código 850 (para o acento de «Versão» no filtro encontrar a linha). No seu computador, o nome e a versão podem ser outros. Pratique só com o mesmo filtro, sem pedir o relatório completo. Não inventamos nem traduzimos mensagem de erro.

A ideia: pedir só o nome e a data de nascimento

Você não pede a ficha inteira da pessoa: só o nome e a versão. O findstr é esse recorte. A ficha completa do systeminfo fica no armário, sem caixa nesta aula.

1. Nome e versão, com o findstr

A coleta rodou o systeminfo e deixou passar só as linhas que começam com Nome do sistema operacional e Versão do sistema operacional. O pedido demora uns 20 segundos. Estas foram as duas linhas:

C:\Users\ana\guia-cmd-teste>systeminfo | findstr /b /c:"Nome do sistema operacional" /c:"Versão do sistema operacional"
Nome do sistema operacional:               Microsoft Windows 10 Pro for Workstations
Versão do sistema operacional:             10.0.19045 N/A compilação 19045
C:\Users\ana\guia-cmd-teste>
systeminfo
o relatório do Windows, que nesta aula não aparece inteiro.
findstr /b
fica só com as linhas que começam com o texto pedido.
/c:"…"
cada trecho procurado: o nome e a versão do sistema operacional.

O nome saiu Microsoft Windows 10 Pro for Workstations. A versão saiu 10.0.19045 N/A compilação 19045. No seu PC, essas duas linhas podem ser outras; o recorte é o mesmo.

O que esta aula não pede para rodar

O systeminfo sem filtro devolve a ficha completa da máquina. Ele aparece aqui só para você reconhecer o risco, sem caixa de execução:

FormaPor que não entra na prática desta aula
systeminfo (sem findstr)A saída completa traz dados demais da máquina. Esta coleta usa só o filtro de nome e versão.

Formas diferentes
