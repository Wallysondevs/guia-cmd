A Data (date /t)

O date sozinho pede para você alterar a data e pode esperar uma resposta. A forma desta aula é o date /t: só mostra a data e devolve o prompt. As saídas abaixo são as da coleta do lote 2e, nesta pasta de teste, no dia da captura.

Você vai aprender
  • O date /t, que mostra a data do sistema sem pedir alteração.
  • A variável %DATE%, que nesta coleta trouxe a mesma data, num echo.
  • Que o date /t desta coleta deixou um espaço no fim da linha — inclusive quando a saída foi para um arquivo.

Todas as saídas desta aula foram colhidas no Prompt de Comando de um Windows em português, na pasta de teste C:\Users\ana\guia-cmd-teste. No seu computador, a data será a do seu sistema, no mesmo formato que o Prompt usar. Pratique numa pasta de teste parecida, não na raiz do disco.

A ideia: olhar o calendário, sem virar a folha

Você quer saber que dia é hoje, não mudar o relógio da parede. A chave /t pede só a leitura.

1. Só ver a data

O date /t mostrou a data e devolveu o prompt. A linha veio com um espaço no fim:

C:\Users\ana\guia-cmd-teste>date /t
20/11/2026 
C:\Users\ana\guia-cmd-teste>

O echo Hoje é %DATE% repetiu a mesma data, desta vez sem o espaço no fim:

C:\Users\ana\guia-cmd-teste>echo Hoje é %DATE%
Hoje é 20/11/2026
C:\Users\ana\guia-cmd-teste>

Mandando a saída para um arquivo e lendo com o type, o espaço do date /t também foi para o arquivo:

C:\Users\ana\guia-cmd-teste>date /t > hoje.txt & type hoje.txt
20/11/2026 
C:\Users\ana\guia-cmd-teste>

Formas diferentes de ver a data

FormaQuando usar
date /tPara ver a data e continuar no prompt, sem diálogo.
echo %DATE%Para usar a data no meio de um texto. Nesta coleta, veio a mesma data, sem o espaço do date /t.
date /t > hoje.txtPara gravar a data num arquivo. O type mostrou o espaço no fim.
dateNão entra nesta coleta: sozinho, o comando pede uma data nova e pode esperar você responder.

Referência rápida
