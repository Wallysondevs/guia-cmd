if

O if é uma bifurcação: o Prompt confere uma condição e, conforme o resultado, executa um pedido ou outro. Nesta aula você vê a igualdade com ==, a chave /i, o if exist, o if not, o if errorlevel e o else com parênteses. As respostas reais ainda estão a coletar.

Você vai aprender
  • O if "Ana"=="ana" e o if /i, que ignora maiúsculas, com else entre parênteses.
  • O if exist e o if not exist, para arquivo ou pasta na pasta de teste.
  • O if errorlevel 1 e o if not errorlevel 1, depois de um comando que falhou ou deu certo. E o if %errorlevel% NEQ 0 na mesma linha: no lote 2b a frase deu erro não foi impressa, por causa da expansão antecipada.

A ideia: uma bifurcação na estrada

O Prompt chega numa placa: “se isto for verdade, vá por aqui; senão, vá por ali”. O if é essa placa. Os parênteses agrupam o que deve rodar em cada lado, principalmente quando há um else.

1. O arquivo existe?

O if exist confere se o nome está na pasta. O if not exist inverte a pergunta. Com uma barra no fim, fotos\ deixa claro que você está falando de uma pasta:

C:\Users\ana\guia-cmd-teste>if exist notas.txt echo notas.txt existe

2. Igualdade, /i e else

A comparação clássica usa ==. Sem a chave /i, "Ana" e "ana" são diferentes. Com /i, maiúsculas e minúsculas não importam. O else vai entre parênteses, junto com o pedido de cada lado:

C:\Users\ana\guia-cmd-teste>if "Ana"=="ana" (echo iguais) else (echo diferentes)

3. Depois de um comando: if errorlevel

O if errorlevel 1 é verdadeiro quando o código de saída é 1 ou maior — em geral, quando o comando anterior falhou. O if not errorlevel 1 é o outro lado: o código foi menor que 1, em geral zero, e o comando deu certo.

C:\Users\ana\guia-cmd-teste>dir nada.txt >nul 2>&1 & if errorlevel 1 echo o dir deu erro

« saída a coletar »

C:\Users\ana\guia-cmd-teste>
C:\Users\ana\guia-cmd-teste>dir notas.txt >nul & if not errorlevel 1 echo o dir deu certo

« saída a coletar »

C:\Users\ana\guia-cmd-teste>

A forma if %errorlevel% NEQ 0 também existe, mas na mesma linha o Prompt expande o %errorlevel% antes de o dir rodar. O lote 2b coletou isso: a mensagem Arquivo não encontrado apareceu, e a frase deu erro não foi impressa, porque o teste ainda viu o código antigo (zero). Formas diferentes de usar o if

FormaQuando usar
if exist notas.txt echo …Para agir só se o arquivo (ou a pasta) existir.
if not exist nada.txt echo …Para agir só se o nome não existir.
if "Ana"=="ana" (… ) else (… )Para comparar textos. Os parênteses agrupam cada lado do else.
if /i "Ana"=="ana"A mesma comparação, sem diferenciar maiúsculas.
if errorlevel 1Para agir quando o comando anterior falhou (código 1 ou maior).

Quando dá errado

Sintaxe incompleta

Você digitaO que faz

Resumo

  • if exist e if not exist conferem se o nome está na pasta de teste.
  • == compara textos; /i ignora maiúsculas; o else vai com parênteses.
