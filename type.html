Lendo Arquivos (type)

Listar o nome não basta: às vezes você quer ler o que está dentro. O type escreve na tela o conteúdo de um arquivo de texto. Nesta aula você lê os arquivos da pasta de teste e vê o que o cmd responde quando o alvo não é um arquivo que se possa ler.

Você vai aprender
  • O type, que mostra o conteúdo de um arquivo de texto.
  • A ler um arquivo numa subpasta, com o caminho relativo, como fotos\legenda.txt.
  • Os erros reais de um arquivo que não existe, de apontar o type para uma pasta e de um caminho que não existe.

Todas as saídas desta aula foram colhidas no Prompt de Comando de um Windows em português, na pasta de teste C:\Users\ana\guia-cmd-teste. Nela já existiam, entre outros, os arquivos notas.txt, relatorio.txt, agenda.txt e rascunho.tmp e as pastas fotos, docs, backup e lixeira. No seu computador, pratique numa pasta de teste parecida, não na raiz do disco.

Não rodamos type no relatorio.docx nem nos .png de mentira da semente: eles só existem para aparecer no dir.

A ideia: abrir a carta e ler em voz alta

O arquivo é uma carta dentro da gaveta. O type abre a carta e lê o texto em voz alta, na tela. Ele não edita, não copia e não apaga: só mostra.

1. Ler um arquivo da pasta atual

O notas.txt da pasta de teste é uma lista de compras. O type mostrou isto:

C:\Users\ana\guia-cmd-teste>type notas.txt
Lista de compras
- pão
- leite
- café

C:\Users\ana\guia-cmd-teste>
type
o comando: “mostre o conteúdo deste arquivo”.
notas.txt
o arquivo, na pasta atual.

O relatorio.txt trouxe outra mensagem, em duas linhas:

C:\Users\ana\guia-cmd-teste>type relatorio.txt
Relatório da semana
Tudo certo na pasta de teste do guia.

C:\Users\ana\guia-cmd-teste>

2. Um arquivo numa subpasta

O caminho relativo fotos\legenda.txt aponta para um arquivo dentro de fotos:

C:\Users\ana\guia-cmd-teste>type fotos\legenda.txt
Fotos das férias (arquivos de exemplo).

C:\Users\ana\guia-cmd-teste>

Formas diferentes de ler um arquivo

FormaQuando usar
type notas.txtO jeito deste guia: ler um arquivo de texto da pasta atual.
type fotos\legenda.txtQuando o arquivo está numa subpasta, com o caminho relativo.
type notas.txt relatorio.txtO type aceita mais de um arquivo na mesma linha. A captura dessa forma, no laboratório, veio com ruído do invólucro da coleta; por isso não usamos essa saída como modelo. No Prompt aberto, experimente você mesmo.

Quando dá errado

Um arquivo que não existe

O type arquivo-nao-existe.txt devolveu esta mensagem:

C:\Users\ana\guia-cmd-teste>type arquivo-nao-existe.txt
O sistema não pode encontrar o arquivo especificado.

C:\Users\ana\guia-cmd-teste>
Apontar o type para uma pasta

fotos é uma pasta, não um arquivo. O cmd respondeu:

C:\Users\ana\guia-cmd-teste>type fotos
Acesso negado.

C:\Users\ana\guia-cmd-teste>
Um caminho que não existe

Com type pasta-nao-existe\a.txt, a mensagem foi esta:

C:\Users\ana\guia-cmd-teste>type pasta-nao-existe\a.txt
O sistema não pode encontrar o caminho especificado.

C:\Users\ana\guia-cmd-teste>

Resumo

  • type arquivo.txt mostra o conteúdo de um arquivo de texto, sem alterá-lo.
  • Com um caminho relativo, você lê um arquivo que está numa subpasta.
  • Arquivo inexistente, pasta no lugar de arquivo e caminho inexistente devolvem mensagens reais, que não se traduzem.
