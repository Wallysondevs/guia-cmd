Onde Está o Comando (where)

Às vezes você quer saber qual arquivo o Prompt vai rodar quando você digita um nome. O where procura esse nome no caminho de busca (o PATH) e mostra a localização. Com /r, ele também procura a partir de uma pasta. As saídas desta aula são as da coleta do lote 2.

Você vai aprender
  • O where nome, que mostra onde o sistema acha esse comando ou programa.
  • O where /r pasta padrão, que procura a partir de uma pasta (nesta coleta, a pasta de teste).
  • A mensagem real quando o nome não é encontrado.

Todas as saídas desta aula foram colhidas no Prompt de Comando de um Windows em português, na pasta de teste C:\Users\ana\guia-cmd-teste. Nela, neste lote, já existiam, entre outros, os arquivos notas.txt, relatorio.txt, agenda.txt, nomes.txt, log.txt e rascunho.tmp, o oculto um-oculto.txt e as pastas fotos, docs, backup e lixeira. No seu computador, pratique numa pasta de teste parecida, não na raiz do disco.

A ideia: perguntar no balcão “quem atende este pedido?”

Você chega ao balcão e pergunta: “quando eu peço cmd, quem responde?”. O where aponta a porta da sala — o caminho do arquivo. Ele não roda o programa: só mostra onde ele está.

1. Localizar um comando

O where cmd devolveu este caminho, exatamente assim:

C:\Users\ana\guia-cmd-teste>where cmd
C:\Windows\System32\cmd.exe

C:\Users\ana\guia-cmd-teste>
where
o comando: “onde está este nome?”.
cmd
o nome procurado no caminho de busca.

2. Procurar a partir de uma pasta

O where /r . *.png (o ponto é a pasta atual, a de teste) listou os dois .png de fotos. O where /r . notas.txt mostrou o caminho do arquivo na pasta de teste:

C:\Users\ana\guia-cmd-teste>where /r . *.png
C:\Users\ana\guia-cmd-teste\fotos\ferias.png
C:\Users\ana\guia-cmd-teste\fotos\praia.png
C:\Users\ana\guia-cmd-teste>where /r . notas.txt
C:\Users\ana\guia-cmd-teste\notas.txt

C:\Users\ana\guia-cmd-teste>

Formas diferentes de perguntar

FormaQuando usar
where cmdPara ver o caminho do cmd que o Prompt encontraria.
where /r . *.pngPara procurar um padrão a partir da pasta atual.
where /r . notas.txtPara achar um arquivo a partir da pasta atual.

Quando dá errado

Um nome que não está no caminho

O where comandoinexistente devolveu esta mensagem, exatamente assim. A mesma frase apareceu com where /r . *.xyz:

C:\Users\ana\guia-cmd-teste>where comandoinexistente
INFORMAÇÕES: não foi possível localizar arquivos para o(s) padrão(ões) especificado(s).
C:\Users\ana\guia-cmd-teste>where /r . *.xyz
INFORMAÇÕES: não foi possível localizar arquivos para o(s) padrão(ões) especificado(s).

C:\Users\ana\guia-cmd-teste>

Referência rápida

Você digitaO que faz
where nomeMostra o caminho em que o sistema acha esse nome.
where /r pasta padrãoProcura o padrão a partir da pasta indicada.

Resumo

  • where nome mostra o caminho do programa correspondente no caminho de busca.
  • where /r pasta padrão procura a partir de uma pasta. Ele não roda nem altera o programa.
  • A mensagem de nome inexistente entra exatamente como o Prompt a escreveu.
