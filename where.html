Onde Está o Comando (where)

Às vezes você quer saber qual arquivo o Prompt vai rodar quando você digita um nome. O where procura esse nome no caminho de busca (o PATH) e mostra a localização. As saídas reais ainda estão a coletar. Se algum caminho apontar para a pasta pessoal de um usuário real, a Mira anonimiza antes de a aula usar a captura.

Você vai aprender
  • O where nome, que mostra onde o sistema acha esse comando ou programa.
  • Que o resultado é um caminho; esta aula não inventa esse caminho.
  • A chave /q, que só indica se achou ou não (silencioso) — a saída real está a coletar.
Saída a coletar. O PC usado na coleta está offline. Estas aulas do lote 2 já têm a explicação, os exercícios e as missões com o código; as respostas do Prompt só entram quando a Mira liberar o arquivo anonimizado em _saidas-anon/. Não complete as caixas de memória e não traduza mensagem de erro.

Quando as saídas reais chegarem, elas terão sido colhidas no Prompt de Comando de um Windows em português, na pasta de teste C:\Users\ana\guia-cmd-teste. No seu computador, pratique numa pasta de teste parecida, não na raiz do disco. Nada nesta aula foi inventado: cada caixa de terminal ainda mostra o placeholder « saída a coletar », que não é resposta do cmd.

A ideia: perguntar no balcão “quem atende este pedido?”

Você chega ao balcão e pergunta: “quando eu peço find, quem responde?”. O where aponta a porta da sala — o caminho do arquivo. Ele não roda o programa: só mostra onde ele está.

1. Localizar um comando

Pedidos típicos, que a coleta pode usar (a resposta, com o caminho real já anonimizado se precisar, entra depois):

C:\Users\ana\guia-cmd-teste>where find

« saída a coletar »

C:\Users\ana\guia-cmd-teste>
C:\Users\ana\guia-cmd-teste>where cmd

« saída a coletar »

C:\Users\ana\guia-cmd-teste>
where
o comando: “onde está este nome?”.
find
o nome procurado no caminho de busca.

Formas diferentes de perguntar

FormaQuando usar
where findPara ver o caminho do find que o Prompt encontraria.
where cmdPara ver o caminho do próprio Prompt.
where /q findPara só perguntar se existe, sem listar o caminho. A saída real está a coletar.

Quando dá errado

Um nome que não está no caminho

O where comandoinexistente devolve alguma resposta (mensagem ou código de saída). O texto real ainda está a coletar — não inventamos nem traduzimos.

C:\Users\ana\guia-cmd-teste>where comandoinexistente

« saída a coletar » — saída real, nunca inventar

C:\Users\ana\guia-cmd-teste>

Referência rápida

Você digitaO que faz
where nomeMostra o caminho em que o sistema acha esse nome.
where /q nomePergunta em silêncio se o nome existe no caminho de busca.

5. Por que esta aula não mostra ainda um caminho como resposta?

Missão: pergunte ao Prompt onde está o find, com o where.



where find

Missão: repita a pergunta para o próprio cmd.



where cmd

Resumo

  • where nome mostra o caminho do programa correspondente no caminho de busca.
  • Ele não roda nem altera o programa.
  • O caminho real ainda está a coletar; se vier pasta pessoal, entra já anonimizado.
